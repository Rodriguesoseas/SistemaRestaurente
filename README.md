# 🍢 Sistema de Gestão para Espetaria

Sistema web desenvolvido para facilitar a administração de uma espetaria, centralizando o controle operacional em uma plataforma intuitiva, responsiva e prática para o dia a dia do estabelecimento.

O projeto foi pensado para atender às necessidades de pequenos negócios do ramo alimentício, reunindo recursos de controle de caixa, gerenciamento de mesas, pedidos, produtos e estoque em um único sistema.

## 🎯 Objetivo

Desenvolver uma solução digital para otimizar as rotinas administrativas de uma espetaria, melhorar a organização das informações e proporcionar maior controle sobre as operações do estabelecimento.

## ✨ Funcionalidades

- **Dashboard:** centralização de informações para acompanhamento da operação.
- **Controle de caixa:** abertura, fechamento e histórico de caixas.
- **Movimentações financeiras:** registro e acompanhamento de entradas e saídas.
- **Gestão de mesas:** organização das mesas e acompanhamento dos atendimentos.
- **Pedidos e comandas:** registro de itens consumidos, gerenciamento dos pedidos e cálculo do valor total da conta.
- **Gestão de produtos:** cadastro e gerenciamento dos produtos comercializados.
- **Controle de estoque:** acompanhamento dos produtos e das quantidades disponíveis.
- **Relatórios gerenciais:** consulta de informações e movimentações por diferentes períodos.
- **Autenticação de usuários:** acesso controlado às funcionalidades do sistema.
- **Interface responsiva:** adaptação para dispositivos móveis e computadores.

## 🛠️ Tecnologias utilizadas

- **Ruby** — linguagem de programação.
- **Ruby on Rails** — framework de desenvolvimento web.
- **PostgreSQL** — banco de dados relacional.
- **Tailwind CSS** — construção da interface e estilização responsiva.
- **Hotwire (Turbo e Stimulus)** — interatividade e atualização da interface.
- **Devise** — autenticação de usuários.
- **Minitest, Capybara e Selenium** — ferramentas de testes automatizados.

## 💡 Diferenciais do projeto

- Centralização de diferentes processos operacionais em uma única aplicação.
- Interface desenvolvida considerando a rotina de um pequeno estabelecimento.
- Organização de pedidos, mesas e valores para facilitar o atendimento.
- Integração entre funcionalidades administrativas e controle de estoque.
- Consulta de informações para apoiar o acompanhamento das operações.
- Desenvolvimento orientado à resolução de necessidades reais de negócio.

## 📌 Status

**Projeto concluído.**

A aplicação reúne os principais módulos de gestão propostos, com funcionalidades implementadas para apoiar as atividades operacionais e administrativas de uma espetaria.
